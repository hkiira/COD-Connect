Synchronise instantanément et automatiquement les commandes WooCommerce vers votre compte CodConnect avec notifications en temps réel.

== Description ==

Cette extension permet de connecter votre boutique WooCommerce à la plateforme CodConnect en mode 100% "Zero-Code".
Dès qu'un client passe commande, celle-ci est immédiatement transmise à votre instance CodConnect via un webhook sécurisé.

Fonctionnalités :
* Transmission instantanée dès la validation de commande (checkout).
* Appel asynchrone non-bloquant : aucun impact sur le temps de chargement pour vos acheteurs.
* Découverte automatique de vos boutiques enregistrées dans CodConnect.
* Bouton de test de connexion en un clic.
* Historique des dernières commandes synchronisées.

== Installation ==

1. Téléversez l'archive `codconnect-sync.zip` via le menu `Extensions > Ajouter > Téléverser une extension` dans votre administration WordPress.
2. Activez l'extension.
3. Rendez-vous dans `WooCommerce > CodConnect Sync`.
4. Renseignez l'URL de votre serveur CodConnect et votre Consumer Secret.
5. Cliquez sur `Charger les boutiques`, sélectionnez votre boutique et enregistrez.
